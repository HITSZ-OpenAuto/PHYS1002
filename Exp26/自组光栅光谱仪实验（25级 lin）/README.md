# 食用指南

## 实验报告相关

- 报告预习部分的 Czerny-Turner (C-T) 光谱仪的主要光路图，其实就是把实验指导书上的光路图照画了一遍，如果看不清报告里的图可以去看实验指导书。~~其实很多东西都能在指导书上找到答案。~~ 
- 实验数据处理时画的图可能和实验课上用软件测的原始光谱图有细微差别，理论上调出的图越标准，差别就会越小。
- 本人实验报告里的光谱图并不算标准，因此提供了实验指导书里的粗调 Hg 灯光谱图以便参考，请同学们尽量往该图的形状上去调。

## 画图程序相关

- 画图程序使用前请先保证 python 环境已安装，并执行以下命令安装依赖。
```
pip install numpy pandas matplotlib scipy
```
- 把实验课上导出的 `.csv` 文件更名为 `data.csv` ，并放到与画图程序同一目录下，然后执行画图程序，会弹出来一个图像窗口，此时其实已经在同一目录下生成了一个叫 `Hg灯标定光谱.png` 的文件了，那就是需要的图。你可以直接关闭窗口，也可以在弹出的窗口中将图像另存为。
- 请尽量在 Windows 环境下执行此画图程序，Linux 和 MacOS 上可能出现字体错误。
- 画图程序由 ChatGPT 和 deepseek 共同制作。

## 备注
